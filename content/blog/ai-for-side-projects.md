I think an underappreciated aspect of the newly-useful coding agents is how much they help with side projects by knocking
down all the obnoxious "side quests."

Most projects have some "Main Quest" - that thing you're really trying to do. But they always come with a seemingly-endless
series of side quests like setting up repos, configuring the project, setting up a release process, setting up a website, 
and on and on. 

All these things are distractions from what you were trying to do. I didn't start working on [KENETH](https://github.com/breischl/KENETh) as an excuse to mess
with Github Actions, or to set up Hugo to build a static site. It was the other way around - KENETH drove the need for those
other things! Despite being side quests, and well within my capabilities to figure out, dealing with them can suck up time and motivation.
I could have easily spent several evenings reading docs and debugging those things! My brother compared these to the 
[Lilliputian's restraints](https://gulliverstravels.fandom.com/wiki/Lilliputians) from Gulliver's Travels -
individually easy to overcome, but each one saps your strength until all forward progress stops. 

Using Claude to help me knock complete those side quests has been really helpful. Sure, I didn't learn much about Hugo static site,
or setting up Github Actions, but I didn't _want_ to learn about those things. If I had been working in a corporate setting
I would likely have tapped a DevOps team to help me with those functions. Since I don't have a DevOps team, I tapped Claude
instead. In either case I would've forgotten the details about five minutes after I was done working on it, and not felt
like I had lost anything that was super important to my Main Quest.
